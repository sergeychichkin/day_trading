# SPY five-minute Exit 3 and trade report

## Purpose

Evaluate Entry 1 with a protective stop that can tighten and carry overnight, and make it possible to inspect the full trade and its price excursions in the standalone report. The scope is the SPY five-minute backtest and its report.

## Approaches

- Extend the current session-by-session replay to carry a position, its active stop, and its excursion measurements between sessions. The session boundary remains the point to reset Entry 1 setup state, update prior daily levels, and check the carried stop against the session open. This is the selected approach.
- Replay all bars in a single chronological state machine. A single loop could make it easier to add overlapping positions later, but would require moving more of the existing Entry 1 setup and order logic into the new loop.

## Configuration

- Keep `entry1_start_time` and `entry1_end_time` under `[entry1]` in `config/SPY.toml`. Remove the two CLI overrides and update the invocation examples. Preserve the existing inclusive New York candle-start window and its `09:30` through `09:40` defaults.
- Set Exit 1 (same-day close) and Exit 2 (next-session open) to disabled and enable Exit 3 in the shipped configuration. Keep the existing two options available by configuration and keep enabled scenarios independent. An older TOML that explicitly enables one of the legacy exits can still reproduce that scenario.
- Add independent chart defaults for the `high + ATR(20) × 0.25` and `low − ATR(20) × 0.5` overlays. Both overlays start off and can be toggled independently in the report. Each multiplier is configurable in TOML. The overlay settings affect display only. Exit 3 uses its specified `0.5` multiplier.

## Exit 3 replay

- Entry 1 uses its existing signal, bear candle, buy stop, sizing, fill and initial protective stop rules. A scenario can have at most one open position. While carrying a position, skip setting up new entries. If a carried position stops out during a new session's signal window, that candle may qualify as a fresh signal at its close when the portfolio is flat. The fresh order still needs a later bear candle and follows the existing activation rules. Keep the one-setup-per-session rule for setups started in the current session.
- Use the plotted daily `lower` prices from the two immediately preceding NYSE trading sessions. These are price levels calculated from the daily opens and `avg_min`. Test `high < lower` against either available level, which is equivalent to testing against the higher of the two when both exist. If one level is unusable, use the other. If neither is usable, the stop stays in place. The two session dates stay fixed for the current session, including when a level is missing. Consult the daily snapshot before the requested replay start when resolving these dates.
- Validate each prior lower against its own daily opening price using the existing lower-level bounds. When a verified five-minute open is available for that date, also apply the existing 5% opening-price consistency guard. A prior date before published five-minute coverage can use a valid daily snapshot level by itself. Record when a level was used without an intraday comparison or skipped because it was missing or invalid.
- On each five-minute bar, apply the active stop first, using the existing OHLC execution and ambiguity rules. A carried position that opens at or below the stop exits at the open reference with the existing modeled costs. Overnight and extended-hours bars are outside the replay.
- At the close of a bull candle (`close > open`), if the position is still open and the candle high is strictly below either prior lower level, calculate `low − 0.5 × ATR(20)` using the ATR including that candle. Round down to the configured price tick. Raise the stop only when the rounded price exceeds the current stop. The new stop applies from the next bar, including at the next regular-session open after a qualifying closing bar. The entry bar may qualify at its close if it meets the same conditions and the position survives. A missing ATR leaves the stop in place.
- Record each adjustment with the triggering candle, effective time, and old and new prices. Plot the active stop as segments at the applicable prices, across sessions for carried positions. Keep the reason for a protective stop exit and the original stop for risk reporting. Apply gap measurement against the stop active at exit.
- The Exit 3 replay ends at the last regular-session close in the requested range. Show an open position separately with its entry, the stop active on the last bar, and any higher stop scheduled for the following regular-session open. Mark unrealized P&L at the last available close, deducting the modeled entry commission and leaving hypothetical exit costs out of the mark. Use completed trades for realized P&L and closed-balance statistics. Charting and open-position reporting do not generate a forced exit or extend the replay.

## Chart and logs

- Load the selected calendar month and the following calendar month in one ordered chart using the bars available in the report. Preserve regular-session timestamps and allow scrolling across the month boundary without reloading the chart. A log jump to a session already loaded focuses that session in the current view. If the next calendar month has no report bars, show the selected month. Apply the same two-month window to the order events shown below the chart.
- Overlay volume on its own scale in the lower part of the price pane. Draw the 20-bar simple average on the same volume scale, using consecutive verified five-minute bars across sessions and month boundaries. Seed the average from available earlier verified bars and omit it until 20 bars are available. The chart uses the cache's existing volume unit.
- Plot the two configurable thin ATR overlays at candle timestamps using each completed bar's existing Wilder ATR(20). For example, the controls can read `High + 0.25 ATR` and `Low − 0.5 ATR` with unchecked boxes. Omit overlay points while ATR is unavailable.
- In the Executed Trades Log, keep the entry session date and show Signal candle, Bear candle, and Entry time as New York `HH:mm`. Keep the exit date visible for multi-session trades. Remove Trigger, Adverse gap vs. trigger/stop, and Ambiguous from that table. Keep the underlying execution details available in the report audit data and existing event and summary views where applicable.
- Add `MFE (R)` and `MAE (R)` as nonnegative magnitudes for completed trades. Use the simulated entry fill minus the original stop as one unit of risk per share. Measure favorable and adverse movement from the entry fill, excluding commissions. Use full ranges for bars held throughout. For partial entry or exit bars, include the simulated fills and any market prices that can be placed within the holding interval from the available OHLC and execution rules. For example, an intrabar entry followed by a surviving position can use the entry candle's high and close, while its low could have occurred before entry. An intrabar stop-out can use an opening price observed while still holding but cannot assume the candle's high preceded the stop. Include opening gaps through the stop via the simulated exit fill. These are OHLC-based excursion measurements. Where the order is unknown, the reported excursion may be smaller than the actual excursion.

## Verification

- Verify strict bull and prior-level comparisons, consecutive trading sessions across a weekend, missing levels, cross-source opening mismatch, daily-only history before five-minute coverage, next-bar stop activation, rounding, monotonic stop changes, overnight gaps through adjusted stops, signal eligibility with a carried position, and a stop adjustment pending at the replay cutoff. Verify unchanged executions for the legacy modes when explicitly selected.
- Verify excursion measurements with an intrabar entry, a same-bar stop, a carried trade and a gap exit. Confirm that stop adjustments preserve the original denominator and that an unfinished position contributes no realized trade P&L.
- Check the standalone report in a browser with data on both sides of a month boundary, an exit logged in a different month, volume SMA continuity, overlay toggles and settings, revised columns, and the charted stop adjustments. Use the existing verified caches read-only for a bounded replay.
