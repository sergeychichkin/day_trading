# Browser interfaces

## Overview

The static assets implement the local historical-candle viewer and a separate
opening-range backtest report. The report generator embeds its assets into the
generated HTML.

## Interface

- `index.html` and `chart.js` provide the cache viewer. `chart.js` requests
  `/api/months` and `/api/month/<YYYY-MM>` from the local server.
- `opening-range.html` and `opening-range.js` render report data and controls
  for rule versions, scenarios, months, orders and trades.
- [Bundled chart library](./vendor/EGM.md): the chart rendering dependency.

## Invariants

- `chart.js` displays times in `America/New_York`, computes a 20-bar volume
  average and resets estimated VWAP by session. Its selection counter prevents
  a stale month response from replacing a newer selection.
- `opening-range.js` expects the report data generated by
  `backtest_opening_range.py` and embedded by `opening_range_report.py`.

## Side Effects

- `chart.js` fetches month data and updates the page and chart objects.
- `opening-range.js` updates report controls, chart series and selected rows in
  the browser; the report script does not request data from the server.

## Verification

- From the repository root: `.\.venv\Scripts\python.exe -m pytest -q`.
  Browser tests require a supported browser as described in `../../README.md`.

## SPY five-minute view

`spy-5m.html` and `spy-5m.js` use the five-minute month index and payload.
They display UTC data in New York time, show missing candle slots rather than
filling them, and draw separate VWAP and daily level lines for each session.
The month selection counter prevents older responses from changing the view.

## SPY five-minute Entry 1 report

`spy-5m-report.html` and `spy-5m-report.js` render the offline replay payload
with embedded chart assets. Trade and order-event controls focus the price
chart on the selected session. Exit and ambiguity markers distinguish chart
events; the gap-cost column excludes overnight movement that does not pass
the trigger or stop.
